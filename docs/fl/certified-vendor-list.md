- On the web page but **not** on the PDF: **PaperTracker**.

- An earlier snapshot exists for delta analysis: https://documents.myflcourtaccess.com/uploads/2022/03/E-FilingAuthority_Certified_Vendors_03012022.pdf (March 1, 2022 list).

## Observations for gap analysis

- Certification is granular: per filing path (New/Existing) x per division, with explicit restriction tiers ("Full" vs "Limited"). Common limited-tier restrictions: no fee-bearing submissions, one document per submission, no Correction Queue handling, no Abandoned Filing Queue handling — implying these are separately certified capabilities.
- Most vendors are certified only in civil divisions (CA/CC/SC). Only eFileMadeEasy, InfoTrack, and Caffeine Code hold all-division Existing Case certification.
- Law firms (Morgan & Morgan, Kahane, RAS, Landau) are certified as vendors for their own filing volume — confirming firms can be TPVs.
